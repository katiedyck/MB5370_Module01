# MB5370 Module 1: Introduction to Programming

This repository contains data and R code on introductory R coding concepts.

<u>**Workshop 1**</u> is a basic introduction to R, including: how to create variables and functions, debugging R code, changing variable types, data frames vs tibbles, and what package libraries are.

<u>**Workshop 2**</u> focused on visualizing data in R, specifically with the `ggplot2` package. It covers different geom types (point, line, bar vs column, etc.), plotting aesthetics (e.g. color, shape, size, alpha), `facet_wrap` and `facet_grid`, and transforming your data to view various statistics, such as count, frequency, and proportion.

<u>**Workshop 3**</u> taught us how to connect an RStudio file or project to a GitHub repository using the R package `usethis`. This is a great way to save your code for personal use or to share with others. My code for this workshop includes all the R commands I ran to connect my code to this repository.
