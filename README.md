# MB5370 Module 1: Introduction to Programming

This repository documents four computer workshops from the JCU MB5370 Introduction to Programming module, covering R syntax and a broad range of R coding concepts essential for working with scientific data.

| Workshop | Topic | Summary |
| :---- | :---- | :---- |
| 1 | Foundations of Programming | A basic introduction to R, including how to create variables and functions, debugging R code, changing variable types, data frames vs tibbles, and what package libraries are. |
| 2 | Visualisations | Introduction to the `tidyverse` package. Visualizing data in R, specifically with the `ggplot2` package. Covers different geom types (`geom_point`, `geom_line`, `geom_bar`, `geom_column`, etc.), plotting aesthetics (e.g. `color`, `shape`, `size`, `alpha`), `facet_wrap` and `facet_grid`, and how to transform your data to view various statistics, such as count, frequency, and proportion. |
| 3 | Reproducible Research in Marine Science | How to connect an RStudio file or project to a GitHub repository using the R package `usethis`. This is a great way to save your code for personal use or to share with others. My code for this workshop includes all the R commands I ran to connect my code to this repository. |
| 4 | Developer's Toolbox & AI | AI tools that you can connect to RStudio to help you write and debug your code, specifically Google Gemini, R's `chattr` package, and GitHub Copilot. Covers the functions `if`, `else`, `if_else`, and `case_when`, and pipe operators (`%>%` and `|>`) which are used to manipulate R code. A basic introduction to writing your own R functions. |
---------------

All four workshops are included within the same Quarto [document](code/MB5370_Module_01.qmd), saved in the `code` folder.

## R and RStudio
**RStudio** is an integrated developer environment (IDE) designed for the R programming language. It is frequently used for computing statistics and visualizing data with the thousands of packages R has to offer. For RStudio to run, R must also be installed - thankfully, they are both free to download!

Instructions on how to download R and RStudio on all operating systems can be found [here](https://rstudio-education.github.io/hopr/starting.html).
