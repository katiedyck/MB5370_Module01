# MB5370 Module 1: Introduction to Programming

This repository contains data and R code on introductory R coding concepts.

**Workshop 1** is a basic introduction to R, including: how to create variables and functions, debugging R code, changing variable types, data frames vs tibbles, and what package libraries are.

**Workshop 2** focused on visualizing data in R, specifically with the `ggplot2` package. It covers different geom types (point, line, bar vs column, etc.), plotting aesthetics (e.g. color, shape, size, alpha), `facet_wrap` and `facet_grid`, and transforming your data to view various statistics, such as count, frequency, and proportion.
