# MB5370 Module 1: Introduction to Programming

This repository contains data and R code on introductory R coding concepts.

- <ins>**Workshop 1**</ins> is a basic introduction to R, including: how to create variables and functions, debugging R code, changing variable types, data frames vs tibbles, and what package libraries are.

- <ins>**Workshop 2**</ins> focused on visualizing data in R, specifically with the `ggplot2` package. It covers different geom types (point, line, bar vs column, etc.), plotting aesthetics (e.g. color, shape, size, alpha), `facet_wrap` and `facet_grid`, and transforming your data to view various statistics, such as count, frequency, and proportion.

- <ins>**Workshop 3**</ins> taught us how to connect an RStudio file or project to a GitHub repository using the R package `usethis`. This is a great way to save your code for personal use or to share with others. My code for this workshop includes all the R commands I ran to connect my code to this repository.

- <ins>**Workshop 4**</ins> covers AI tools that you can connect to RStudio to help you write and debug your code, specifically Google Gemini, R's `chattr` package, and GitHub Copilot. We learned how `if`, `else`, `if_else`, `case_when` and pipe operators (`%>%` and `|>`) are used to manipulate R code. We were also introduced to how writing your own R functions is done.

All four workshops are included within the same Quarto [document](code/MB5370_Module_01.qmd), saved in the `code` folder.
